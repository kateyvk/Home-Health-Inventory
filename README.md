## Home Healthcare Inventory
#### I created this app because I have a disabled father who has spent over 10 years receiving home healthcare. Unlike traditional healthcare, home healthcare is a lot less stringent, and there may not be a perfectly organized system to know when you need to replace some medical supplies. But with this web app, now there is an easy way to track important medical supplies, so you know when to replace or reorder materials. This app also provides a space where the user can create home care training guides for different aspects of the Patient's care. Although not fully developed, this app would allow users like the Patient's family to log in, check the dashboard or alerts page for any low items, and add inventory items and caregiver guides as needed.
